# Alocação dinâmica em C

Exercícios para estudar ponteiros, strings, structs e gerenciamento de memória em C. A ideia é aprender os fundamentos com exemplos contextualizados para a área em que quero atuar: engenharia de software voltada a infraestrutura, cloud e confiabilidade.

Os exercícios incluem leitura de temperaturas, análise de violações de SLA, armazenamento de logs e uma tabela de rotas. Cada pasta contém o enunciado e minha implementação. Os cenários são simplificados e servem para praticar programação.

Estou praticando o uso de `malloc`, `realloc` e `free`, o crescimento de vetores e o tratamento de falhas de alocação.
